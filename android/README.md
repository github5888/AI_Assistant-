# Android runner

This folder is the native Android host for the Flutter app. Its Gradle files use the Flutter Gradle Plugin and are regenerated by `flutter create` in CI so they always match the installed Flutter SDK.

If the checked-in Gradle versions do not match your local Flutter SDK, delete this folder and regenerate it from the project root:

```bash
rm -rf android
flutter create --platforms=android --project-name itsclear_app --org com.itsclear.app --no-overwrite .
```

On Windows PowerShell:

```powershell
Remove-Item -Recurse -Force android
flutter create --platforms=android --project-name itsclear_app --org com.itsclear.app --no-overwrite .
```

`gradle-wrapper.jar`, `gradlew`, `gradlew.bat` and `local.properties` are generated locally and intentionally ignored by Git. The GitHub Actions workflow generates them before building the APK.
